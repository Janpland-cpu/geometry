习题说明
ABOUT

结构简单，方便一直往里加题。

没有框架、数据库或构建流程；GitHub Pages 可以直接托管。

网站怎么组织

首页只读取一份目录清单；每道题自己保存在 problems/<id>/ 下。详情页只有一个通用的 problem.html，所以以后增加几十道题也不需要复制整套页面。

目录负责“有哪些题”　·　题目文件负责“这道题写什么”

新增一道题：4 步

1

复制模板

复制 problems/_template/，改名为例如 geo-002/。

2

填写 data.js

写题目、目标、标签以及一个或多个解法步骤。

3

放示意图

推荐 SVG；如果有互动演示，再放进该题自己的 demos/。

4

登记到目录

在 assets/js/catalog.js 增加一条元数据。推送 GitHub 后首页自动出现新题。

部署到 GitHub Pages

把全部文件上传到仓库根目录，然后进入 Settings → Pages，选择 Deploy from a branch，分支选 main，目录选 /(root)。

详细维护说明同时保存在仓库的 README.md 与 ADD_PROBLEM.md。

设计原则

复杂度纯 HTML / CSS / JavaScript
数据每题一个 data.js
公式原生 HTML，不依赖 CDN
进度浏览器 localStorage
部署GitHub Pages

为什么这样做

现在只有一道题时仍然简单；以后题目变多时，也不需要重构。互动解法是可选附件，不会把整个站点绑死在某一种呈现方式上。
